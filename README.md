# Lean Specification for HistFactory

HistFactory is a mathematical specification for probability models. It's widely used for statistical analyses in particle physics.

The aim of the Lean specification is to serve as the authoritative specification of the mathematical content, against which concrete implementations
such as in ROOT, pyhf or histopresto are validated.
